# Bundle Archives

The `genecoder bundle run` command executes the steps defined in a YAML configuration. When the run completes, passing the `--export-archive` flag creates a gzipped tar archive containing the entire run directory.

```
genecoder bundle run workflow.yml --cache-dir runs --export-archive output.tar.gz
```

The archive has the following layout:

- `<timestamp>/encoded/` – FASTA files produced by the encode step
- `<timestamp>/simulated/` – output from channel simulators (if any)
- `<timestamp>/decoded/` – files generated by the decode step
- `<timestamp>/summary.json` – manifest describing the run

The `summary.json` file includes the configuration hash, timestamp and a list of all files in the archive.
